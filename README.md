<h2 align="center">LayBalt Repository</h2>
<h2 align="center">Version 3.0.0</h2>
<h4 align="center">LayBaltQOL (LBQ) is a feature-rich Fabric mod for Hypixel Skyblock on Minecraft 26.2.</h4>

---

<h3 align="center">Mod Information</h3>
<p align="center">
LayBalt mod is a Minecraft Mod made by LayBalt for Hypixel QOL. This mod is a <i>free access mod</i>, as well as <i>free source code</i>. Version 2.0.0 and later run on <b>Fabric for Minecraft 26.2</b> (the 1.x releases were Forge 1.8.9 mods). This mod includes features like:
</p>

- Auto Fishing (with head shake, mouse lock and death / warp detection)
- Auto Clicker (left and right)
- Auto Melody
- Auto Experiment (Chronomatron and Ultrasequencer)
- Custom ESP (middle-click a mob to add it to the ESP list)
- Vampire Slayer helper (Impel: CLICK UP / CLICK DOWN / JUMP / SNEAK)
- Auction Sniper (Only Discord version for now)
- [WE DID NOT PAID FOR HOSTING, DONATE US TO GET IT BACK!]
- Soon...

<h3 align="center">Installation</h3>
<p align="center">
Requires Minecraft 26.2 with <a href="https://fabricmc.net/use/">Fabric Loader 0.19.3+</a> and the following mods in your <code>mods</code> folder:
</p>

- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)
- `LayBaltQOL-<version>-26.2.jar` from the [releases](https://github.com/LayBalt/LayBalt-QOL/releases)
- Optional: [Mod Menu](https://modrinth.com/mod/modmenu) to open the config from the mods list

Type <code>/lbq</code> (or <code>/laybalt</code>) in chat to open the ClickGui. The config is stored in <code>config/LayBaltQOL/</code>.
